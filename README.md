# bmallegri.com

My personal website, live at [bmallegri.com](https://www.bmallegri.com).

Two pages covering who I am, what I'm building, where I've worked, and some drone photography.

## Run Locally

Requires Node.js and npm.

```bash
git clone https://github.com/bmallegri/bmallegri.ai
cd bmallegri.ai
npm i
npm run dev
```
